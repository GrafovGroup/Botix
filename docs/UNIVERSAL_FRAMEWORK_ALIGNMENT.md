# BOTIX — Universal Grafov Group Website Framework Alignment

Status: Mandatory development operating framework for BOTIX and future work in this repository.
Owner approved alignment with the previously established Universal Grafov Group Website Master Prompt on 2026-10-22.

## Priority
Ship a credible, distinctive, bilingual Canadian B2B commercial robotics website that generates qualified inquiries. Humanoid robotics is the flagship, with all commercial robotics categories supported. BOTIX Signature identity: premium black/white/silver. Do not invent supplier relationships, inventory, prices, service capacity, offices or guarantees.

## Universal requirements
- Unique brand identity and distinct layout; never clone another Grafov Group site or merely recolor it.
- English and Québec-appropriate French live from day one, including navigation, forms, errors, metadata, language switching, canonical and hreflang.
- Canada-wide commercial positioning with useful province/territory, major-city and surrounding metro-area content, without duplicate doorway pages or fabricated offices.
- Conversion-first UX: clear calls, relevant category/industry/product/rental pages, contextual quote requests and phone only when verified.
- Responsive, accessible, fast, search-friendly, secure and privacy-conscious.
- Codex owns routine implementation, technical troubleshooting, testing, version control and documentation; owner involvement only for credentials, permissions, legal/commercial facts, design signoff and launch authorization.
- Every phase's prompt, implementation, test evidence and status must be committed to GitHub.
